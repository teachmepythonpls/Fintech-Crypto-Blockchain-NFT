# Fintech-Crypto-Blockchain-NFT

Lab 6: The purpose was to set up a MetaMask wallet, deploy Ethereum smart contracts (ERC-20, ERC-721, and ERC-1155) using Remix IDE, and troubleshoot contract compatibility issues with different EVM versions.

Lab 9: This lab focused on preparing a MetaMask wallet, deploying a smart contract on the Saakuru blockchain, verifying contract details on the Saakuru platform, securing it with a password, and integrating it with a web application.

Lab 10: The goal was to connect to an account via VU VPN, switch to the Sepolia test network, obtain test currency, create and deploy an NFT contract, generate NFT metadata using Visual Studio Code, and mint an NFT token.
